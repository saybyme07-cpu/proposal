# SayByMe — Small Things... Big Emotions... 💖

SayByMe is a romantic proposal web application that lets users create personalized proposals with interactive love letters, romantic memories photo carousels, and a canvas 2D fireworks engine with custom bursts and heart shapes.

## Features

- **Multi-Step Proposal Studio**: Configure sender, recipient, question, personal letter, and celebrations.
- **Interactive Proposal Preview**:
  - Stage 1: Wax-sealed envelope opening animation
  - Stage 2: Romantic intro note
  - Stage 3: Handwritten letter reveal
  - Stage 4: Interactive proposal question with running "No" button
  - Stage 5: Memories Polaroid photo deck (continuous auto-scroll + interactive drag)
  - Stage 6: Canvas 2D heart fireworks engine (7 burst types, spark trails, additive glow, tap to launch)
  - Stage 7: Finale thank you screen
- **Shareable Links**: Backend integration for generating unique, unguessable links for recipients.

## Tech Stack & Architecture

- **Frontend**: HTML5, CSS3, JavaScript / React & Next.js
- **Database & Backend**: Convex
- **Hosting & Deployment**: Vercel
- **Repository**: GitHub
